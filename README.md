# Scan to Me

Scan to Me makes an iPhone or iPad show up in the **Scan to Computer** menu of
network all-in-one printers. Open the app, press Scan on the printer, pick your
phone, and the pages arrive over WiFi as a PDF or JPEG in the folder you chose
(Files, iCloud Drive, any file provider) and optionally in Photos.

Supported today: HP inkjet all-in-ones, through either of their built-in
interfaces: LEDM on models from roughly 2010-2020 (Photosmart, OfficeJet,
ENVY, Deskjet; port 8080, or 80 on some), or eSCL walkup subscriptions on
newer models that dropped LEDM (port 80). The app picks whichever the printer
offers. Nothing is installed on the printer. The app is independent and
not affiliated with or endorsed by any printer manufacturer. It started as the
iOS sibling of the desktop client [hpscan](https://github.com/olibar/hpscan);
the protocol logic was ported, the projects share no code.

## Features

* Finds printers with Bonjour, or takes a hostname / IP by hand. Several
  printers at once.
* Multi-page PDF: "scan another page" on the flatbed, or the whole stack from
  the document feeder. One JPEG per page otherwise.
* Honours the shortcut chosen on the printer (Save as Document -> PDF,
  Save as Photo -> JPEG).
* Files are written atomically into the app folder (visible in the Files app)
  or a folder you pick, including iCloud Drive and other providers. JPEG scans
  can also go to Photos.
* Follows the printer when its IP changes, re-registers after printer reboots.
* Several sites: printers are told apart by their unique network identity, so
  the same model at home and at the office (even on the same IP address) are
  two entries. Each shows whether it is on the current network, and only the
  ones present are contacted. Names come from the Location set in the
  printer's web page, or rename them in the app.

## The iOS constraint

iOS suspends apps in the background, so the phone is only listed on the
printer **while Scan to Me is open and listening**. The app keeps the screen on
during that time. If you leave the app mid-document, the pages already
received are saved as a PDF before the app is suspended, and listening resumes
when you come back.

## Layout

```
Packages/ScanKit     SwiftPM package: LEDM and eSCL clients, session state
                     machine, PDF writer, Bonjour discovery, folder output. No
                     dependencies. Builds and tests on macOS too.
ScanToMe/            The iOS app (SwiftUI). Project generated by XcodeGen.
project.yml          XcodeGen spec; regenerate ScanToMe.xcodeproj after edits.
```

## Build

Requirements: Xcode 16 or later, an Apple developer team for device builds.

```sh
brew install xcodegen          # only if you change project.yml
xcodegen generate              # writes ScanToMe.xcodeproj
open ScanToMe.xcodeproj          # set your team under Signing, run on a device
```

The simulator can build the app but has no access to your LAN's Bonjour
traffic in a useful way; test on a real device.

Core package alone (no Xcode needed beyond the toolchain):

```sh
cd Packages/ScanKit
swift build && swift test
swift run scankit-cli discover
swift run scankit-cli serve 192.168.1.20:8080 --name "Test Mac" --out ~/Scans
```

The `serve` command runs the exact session used by the app from a Mac
terminal, handy to validate a new printer model.

## Using it

1. Printers tab -> + -> tap the printer found on the network (or enter its
   address). The first time, iOS asks for Local Network permission; allow it.
2. Settings: pick the name shown on the printer, format, resolution, and the
   folder to save into.
3. Listen tab -> Start listening. Each printer shows "Ready".
4. On the printer: Scan -> Computer -> your phone's name -> Save as Document
   or Save as Photo -> Start. Keep answering "scan another page" for a
   multi-page PDF; choose Done to close it (or wait for the idle timeout).

## Settings

| Setting | Default | Meaning |
|---|---|---|
| Name shown on the printer | device name | Destination name in the Scan to Computer menu |
| Format | PDF | PDF or JPEG; a PDF/JPEG shortcut chosen on the printer wins |
| Resolution | 300 dpi | 75..1200, clamped to what the scanner reports |
| Color | Color | Color or grayscale |
| Paper | A4 | A4 or Letter scan area |
| File name | `scan_{date}_{time}` | Tokens `{date}` `{time}` `{page}`; `{page}` is used for JPEG pages |
| Close PDF after | 120 s | Idle time before a multi-page PDF is closed without a "Done" |
| Folder | app folder | App Documents folder or any folder picked in Files |
| Also add JPEG scans to Photos | off | Adds JPEG scans to the Photos library (add-only permission) |

## Troubleshooting

* Printer says "no computer found": start listening in the app **before**
  opening the menu on the printer, and check each printer shows "Ready".
* Nothing found when adding a printer: Settings > Privacy & Security > Local
  Network must list Scan to Me as allowed. Or add the printer by address.
* The Activity screen (magnifier icon on the Listen tab) shows what the
  session did; the Copy button puts it on the clipboard for bug reports.
